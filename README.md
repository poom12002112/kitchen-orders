# 點貨助手

盤點庫存、自動算出叫貨量的網頁小工具。可以加到手機主畫面當 App 用，開過一次後不用網路也能使用。

## 功能

- 選擇平日、週五或假日，自動帶入各貨品「要備到的量」
- 填入現有庫存，即時算出每項要叫多少
- 盤點完成後，再詢問沒有固定數量的品項要不要叫
- 產生叫貨清單，一鍵複製
- 支援離線使用（PWA）

## 使用方式

1. 打開網頁，上方選今天要叫貨的日子。預設會依當天星期幾自動選擇：週五選週五，週六日選假日，其他選平日。
2. 逐項填入現有庫存。沒有庫存請填 `0`。
3. 按「盤點完成」。有漏填的品項會被標示出來。
4. 回答幾個沒有固定數量的品項要不要叫。選「要」再填叫貨數量，選「不要」就跳過。
5. 按「產生叫貨清單」，再按「複製清單」貼到要傳送的地方。

庫存不會被儲存，關掉頁面或按「重新開始」就會清空。

## 叫貨規則

### 基本算法

```
叫貨量 = 備到量 − 現有庫存（最少為 0）
```

表上的數字是「要備到的量」，庫存已經夠就不叫。

### 備到量

| 貨品 | 平日 | 假日 | 單位 |
|---|---|---|---|
| 青蔥 | 1 | 2 | 捆 |
| 玉米筍 | 10 | 18 | 盒 |
| 蒜仁 | 1 | 2 | 包 |
| 雪白菇 | 3 | 3 | 包 |
| 鴻禧菇 | 3 | 3 | 包 |
| 海帶結 | 1 | 2 | 包 |
| 竹皮 | 2 | 2 | 包 |
| 洋蔥 | 3 | 5 | 斤 |
| 杏包菇c-3kg | 0.5 | 1 | 包 |
| 大黃瓜 | 3 | 6 | 條 |
| 南瓜 | 5 | 8 | 斤 |
| 白蘿蔔 | 2 | 4 | 斤 |
| 薑絲 | 1 | 2 | 包 |
| 鮮柯 | 3 | 6 | 斤 |
| 青江菜 | 4 | 10 | 斤 |

週五的數量等於平日，只有青江菜例外：平日 4、週五 6、假日 10（斤）。

### 特殊規則

**杏包菇**

- 平日：庫存不足 0.5 包就叫 0.5 包，庫存到 0.5 包以上就不叫
- 假日：庫存不足 1 包就叫 1 包，庫存到 1 包以上就不叫

**白蘿蔔**（叫貨量一律是正整數）

- 平日：缺口不足 1 斤就叫 1 斤，其他缺口進位成整數
- 假日：缺口不足 2 斤就叫 2 斤，超過 2 斤的缺口以 1 斤為單位進位

週五的特殊規則比照平日。

### 沒有固定數量的品項

香竹腸（箱）、豆皮（包）、香菇（包）、蘭花（斤）、小辣椒（包）、俄白菜（斤）沒有設定備到量。盤點完成後會逐項詢問要不要叫，要的話再填數量。

## 部署到 GitHub Pages

1. 建立一個公開（Public）的 repository。
2. 把這個資料夾裡的檔案全部上傳到 repository 最外層。
3. 到 **Settings → Pages**，Source 選 `Deploy from a branch`，分支選 `main`，資料夾選 `/ (root)`，儲存。
4. 等一兩分鐘，網址會是 `https://你的帳號.github.io/專案名稱/`。

也可以用 Netlify Drop：解壓縮後把整個資料夾拖進 app.netlify.com/drop，就會得到一個網址。

## 加到手機主畫面

用手機瀏覽器打開上面的網址：

- **iPhone（Safari）**：分享 →「加入主畫面」
- **Android（Chrome）**：選單 →「安裝應用程式」或「加到主畫面」

第一次要有網路，之後離線也能開。

## 修改貨品與規則

所有設定都在 `index.html` 的 `<script>` 最上面：

- `ITEMS`：貨品表，格式是 `[名稱, 平日, 假日, 單位, 週五]`。週五不填就等於平日。平日填 `null` 代表沒有固定數量，盤點後再詢問。
- `RULE`：特殊叫貨規則，格式是 `品名: { 平日: [進位單位, 最少叫貨量], 週五: [...], 假日: [...] }`。

改完重新上傳之後，請把 `sw.js` 第一行的快取版本號加一（例如 `diaohuo-v4` 改成 `diaohuo-v5`），手機上的版本才會更新。

## 檔案說明

| 檔案 | 用途 |
|---|---|
| `index.html` | 主程式（畫面、貨品表與規則都在這裡） |

## 注意

- 公開的 repository 任何人都看得到內容，貨品表和規則也包含在內。如果介意，網址不要分享出去。
- 沒有使用任何外部套件或網路服務，所有計算都在手機上完成。
